# journeyplanner-connection-explorer
This tool lets the user explore possible and near possible interchanges using the journey planner API. This is currently specified to use the Entur production environment, but the app can be repurposed to use any API endpoint, and any colour scheme.

The purpose of the tool is to allow timetable planners to inspect interchange hubs and evaluate the time window, seeing which connections are possible and which fall short of the mark.
