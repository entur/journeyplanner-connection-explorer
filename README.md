# journeyplanner-connection-explorer
This tool lets the user explore possible and near possible interchanges using the journey planner API. This is currently specified to use the Entur production environment, but the app can be repurposed to use any API endpoint, and any colour scheme.

The purpose of the tool is to allow timetable planners to inspect interchange hubs and evaluate the time window, seeing which connections are possible and which fall short of the mark.

---

https://entur.github.io/journeyplanner-connection-explorer/

---

1. Select a stop in the geocoder
2. Select a date and time-window
3. Pick one of the departures or arrivals
4. See the possible connections. It shows both impossible, near misses and possible connections
6. Inspect details of any chosen connection and see relevant ID's
7. If there are too few, or too many results, adjust the time window, or adjust the two top right settings for walk time (connect with more or fewer stops) or wait time (wait longer or shorter at the stop for a connection)
